<p>Klick'r — это приложение с открытым исходным кодом для Android, созданное для простой автоматизации повторяющихся задач. Ранее известное как Smart AutoClicker, Klick'r сочетает уникальные возможности распознавания изображений с традиционными функциями автоклика, предлагая универсальное решение для всех ваших потребностей в автоматизации.
</p>
<p>Будь вы геймером, автоматизирующим игровые действия, тестировщиком, имитирующим взаимодействия пользователя, или просто человеком, часто выполняющим повторяющиеся клики — Klick'r предлагает как распознавание изображений для сложной автоматизации, так и Простой режим для стандартного автоклика.
</p>

</br>

## Основные возможности:
* **Клики и смахивания**: Автоматизируйте нажатия и смахивания с точной настройкой длительности нажатия, времени смахивания и позиции. Запускайте действия при обнаружении изображений для плавного взаимодействия с динамическими элементами.
* **Расширенная автоматизация**: Улучшайте свои сценарии автоматизации с помощью таких возможностей, как операции со счётчиками, Android Intents и управление ходом выполнения, получая непревзойдённую гибкость.
* **Триггеры**: Настраивайте сложные триггеры на основе распознавания изображений, таймеров, счётчиков и приёмников широковещательных сообщений Android для точной настройки автоматизации.
* **Простой режим**: Простой и удобный автокликер с легкой настройкой, идеально подходящий для менее сложных повторяющихся задач.
* **Учебники**: Освойте Klick'r с помощью интерактивных игровых учебников, которые пошагово помогут вам автоматизировать задачи и выиграть в игре с помощью мощных функций Klick'r.
* **Открытый исходный код**: Проект с открытым исходным кодом, который непрерывно развивается благодаря активному сообществу.
